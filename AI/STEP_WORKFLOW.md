# Step Workflow

## Prompt: @step N

Полный цикл для шага N.

---

## Workflow

```
@step N
    │
    ├─► 1. ДЕТАЛИЗАЦИЯ
    │   Task(unity-architect): создать AI/step_{N}.md
    │   → Показать резюме
    │   → Ждать "Реализовать?"
    │
    ├─► 2. РЕАЛИЗАЦИЯ
    │   Прочитать Parallel Execution Plan из step_{N}.md
    │   Task(unity-programmer) × N параллельно по группам:
    │     Group A (параллельно) → ждать завершения
    │     Group B (после A) → ждать завершения
    │     Group C (после B) → ...
    │   → Показать созданные файлы
    │   → Ждать "Валидировать?"
    │
    └─► 3. ВАЛИДАЦИЯ
        Task(unity-mcp):
          1. read_console → компиляция
          2. run_tests → тесты
        → Показать результат
        → Если OK: "Запусти Setup/Step N в Unity"
```

---

## Агенты

| Agent | Model | Роль |
|-------|-------|------|
| unity-architect | opus | Создаёт `step_{N}.md` со спецификацией |
| unity-programmer | sonnet | Реализует код по спецификации |
| unity-mcp | sonnet | ТОЛЬКО проверка: компиляция + тесты |

---

## Этап 1: Детализация

**Промпт для unity-architect:**

```
Детализируй шаг {N} из AI/plan.md.

Создай AI/step_{N}.md со всеми секциями:
1. Parallel Execution Plan — группы задач для параллельной реализации
2. Components — Model, View, Presenter
3. Interfaces — полные сигнатуры
4. Implementation Specs — полный код каждого компонента
5. Test Specs — тесты для Model и Presenter
6. Scene Setup Script — Editor Menu скрипт
7. Validation Checklist — критерии успеха

Контекст:
- AI/plan.md — описание шага
- AI/UNITY_MVP_ARCHITECTURE_GUIDE.md — архитектура
- AI/UNITY_TDD_GUIDE.md — тестирование

Следуй плану ТОЧНО, без дополнений.
```

**Вывод:**
```
## Step N детализирован

| Группа | Задачи | Файлы |
|--------|--------|-------|
| A | ... | ... |
| B | ... | ... |

Компонентов: X
Тестов: Y
Файлов: Z

Реализовать? (да/нет)
```

---

## Этап 2: Реализация

**Координация параллельных задач:**

1. Прочитать `step_{N}.md` → секция "Parallel Execution Plan"
2. Для каждой группы:
   - Запустить Task(unity-programmer) для каждой задачи группы **параллельно**
   - Ждать завершения всех задач группы
   - Перейти к следующей группе

**Промпт для unity-programmer (Task mode):**

```
Реализуй Task {X} из AI/step_{N}.md.

Твоя задача: {название задачи}
Файлы к созданию:
- {file1.cs}
- {file2.cs}

Создай ТОЛЬКО эти файлы. Не трогай файлы из других задач.
План — закон. Никаких отклонений.

Контекст: AI/step_{N}.md
```

**Вывод:**
```
## Step N реализован

Созданные файлы:
| Группа | Файл | Строк |
|--------|------|-------|
| A | path/file1.cs | 50 |
| A | path/file2.cs | 30 |
| B | path/file3.cs | 80 |

Всего: X файлов

Валидировать? (да/нет)
```

---

## Этап 3: Валидация

**Промпт для unity-mcp:**

```
Валидируй шаг {N}.

Выполни ТОЛЬКО:
1. read_console → проверить ошибки компиляции
2. run_tests → запустить тесты шага

НЕ запускай execute_menu_item — Scene Setup пользователь запустит сам.

Вернуть статус:
✅ PASSED — компиляция OK, тесты OK
❌ FAILED — детали ошибок
```

**Вывод при успехе:**
```
═══════════════════════════════════════
STEP N: VALIDATED ✅
═══════════════════════════════════════

КОМПИЛЯЦИЯ:  ✅
ТЕСТЫ:       X/Y passed

Теперь запусти в Unity: Setup → Step N
```

**Вывод при ошибке:**
```
═══════════════════════════════════════
STEP N: FAILED ❌
═══════════════════════════════════════

КОМПИЛЯЦИЯ:  ❌ [детали]
ТЕСТЫ:       X/Y passed

[Детали ошибок]
```

---

## Критические правила

1. **План — закон** — программисты реализуют ТОЧНО по step_{N}.md
2. **MCP НЕ настраивает сцену** — только read_console + run_tests
3. **Scene Setup** — пользователь запускает сам через Unity меню
4. **Между этапами** — ждать подтверждения пользователя
5. **Параллельность** — группы последовательно, задачи внутри группы параллельно
