## 🎯 Ключевые принципы

### 1. Изоляция контекста
Каждый агент работает в **чистом контексте** — не смешивайте агентов в одном разговоре.

### 2. Документы как источник истины
- `plan.md` — READ-ONLY после создания
- `step_{N}.md` — полная спецификация для шага
- Агенты не импровизируют — следуют документам

### 3. Обязательное тестирование
- Каждый шаг включает тесты
- MCP Agent валидирует перед переходом к следующему шагу

### 4. Автоматизация через MCP
- Компиляция проверяется автоматически
- Сцена настраивается скриптом
- Тесты запускаются и проверяются

## 📋 Фаза 1: Архитектура (unity-architect)

**Вход:** Номер шага из `plan.md`

**Выход:** `step_{N}.md` содержащий:
```markdown
## Step {N}: {Name}

### 1. Components
- ComponentA (Model) — описание
- ComponentB (Presenter) — описание
- ComponentC (View) — описание

### 2. Interfaces
```csharp
public interface IComponentAView { ... }
```

### 3. Implementation Specs
[Полный код каждого компонента]

### 4. Test Specs
```csharp
// ComponentAModelTests.cs
[TestFixture]
public class ComponentAModelTests
{
    [Test]
    public void Method_Condition_ExpectedResult() { ... }
}
```

### 5. Scene Setup Script
```csharp
// Editor/Step{N}SceneSetup.cs
public static class Step{N}SceneSetup
{
    [MenuItem("Setup/Step {N}")]
    public static void Setup() { ... }
}
```

### 6. Validation Checklist
- [ ] Компиляция без ошибок
- [ ] Все тесты проходят
- [ ] Сцена настроена корректно
```

### Фаза 2: Реализация (unity-programmer)

**Вход:** `step_{N}.md`

**Выход:**
- Все `.cs` файлы по спецификации
- Тесты в `Tests/EditMode/`
- Scene Setup скрипт в `Editor/`

**Правила:**
- Код 1:1 со спецификацией
- Никаких "улучшений" или отклонений
- Файлы < 200 строк

### Фаза 3: Валидация (unity-mcp-agent)

**Вход:** Запрос на валидацию шага N

**Действия:**
1. `read_console` — проверить ошибки компиляции
2. `execute_menu_item` — запустить Scene Setup
3. `run_tests` — запустить тесты для шага
4. Дождаться завершения тестов
5. Проверить результаты

**Выход:**
- ✅ Шаг валидирован — можно продолжать
- ❌ Ошибки — список проблем для исправления

## 📝 Главный промт: @step N

**Использование:** `@step N` — запускает полный цикл для шага N.

```
@step N

Полный цикл для шага N:

1. ДЕТАЛИЗАЦИЯ
   → Task(unity-architect): создать AI/step_{N}.md
   → Показать резюме
   → Ждать "Реализовать?" → да

2. РЕАЛИЗАЦИЯ
   → Прочитать Parallel Execution Plan из step_{N}.md
   → Task(unity-programmer) × N параллельно по группам
   → Показать созданные файлы
   → Ждать "Валидировать?" → да

3. ВАЛИДАЦИЯ
   → Task(unity-mcp): компиляция + тесты + execute_menu_item("Setup/Step N")
   → Показать результат

Между этапами ждать подтверждения пользователя.
```

### Промт для архитектора (внутренний)

```
Детализируй шаг {N} из AI/plan.md.

Создай AI/step_{N}.md со всеми секциями:
- Parallel Execution Plan (группы задач)
- Components (Model, View, Presenter)
- Interfaces
- Implementation Specs (полный код)
- Test Specs
- Scene Setup Script
- Validation Checklist

Контекст: AI/UNITY_MVP_ARCHITECTURE_GUIDE.md, AI/UNITY_TDD_GUIDE.md
```

### Промт для программиста (внутренний)

```
Реализуй Task {X} из AI/step_{N}.md.

Создай ТОЛЬКО файлы из твоей задачи:
- [список файлов задачи]

План — закон. Никаких отклонений.
```

### Промт для MCP агента (внутренний)

```
Валидируй шаг {N}.

1. read_console → проверить компиляцию
2. execute_menu_item("Setup/Step {N}") → запустить Scene Setup скрипт
   ⚠️ НЕ создавать сцену вручную! Только execute_menu_item!
3. run_tests → запустить тесты
4. Вернуть статус: ✅ PASSED или ❌ FAILED с деталями

Если Scene Setup не работает → спросить пользователя что делать.
```

## 🛠️ MCP Tools Reference

### Проверка компиляции
```
read_console
└── Возвращает ошибки/предупреждения из Unity Console
```

### Запуск Scene Setup
```
execute_menu_item
└── path: "Setup/Step {N}"
```

### Запуск тестов
```
run_tests
└── testFilter: "Step{N}" или конкретные тесты
└── testMode: "EditMode" | "PlayMode"
```

### Проверка состояния
```
resources: editor_state
└── Возвращает: play mode, compilation status, etc.
```

## ⚠️ Критические правила

### ДЛЯ АРХИТЕКТОРА
- ✅ Всегда включай Test Specs
- ✅ Всегда включай Scene Setup Script
- ✅ Код должен быть полным, не stub-ами
- ❌ Не пропускай секции

### ДЛЯ ПРОГРАММИСТА
- ✅ Следуй step_{N}.md буквально
- ✅ Создавай ВСЕ файлы из спецификации
- ❌ Не добавляй код "от себя"
- ❌ Не пропускай тесты

### ДЛЯ MCP АГЕНТА
- ✅ Дожидайся завершения тестов
- ✅ Проверяй ВСЕ тесты шага
- ❌ Не продолжай при ошибках компиляции
- ❌ Не игнорируй failed тесты

## 🔧 Troubleshooting

### Проблема: Тесты не запускаются
```
1. Проверь asmdef — тесты должны ссылаться на Runtime
2. Проверь namespace — должен совпадать с asmdef
3. Проверь атрибуты [TestFixture], [Test]
```

### Проблема: Scene Setup не в меню
```
1. Скрипт должен быть в Editor/ папке
2. Класс должен быть static
3. Метод должен иметь [MenuItem("...")]
```

### Проблема: MCP не подключается
```
1. Проверь Window > MCP for Unity
2. HTTP Server должен быть запущен
3. Проверь статус подключения
```
